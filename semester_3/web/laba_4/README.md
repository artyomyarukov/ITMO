# Point Area Analyzer

Full-Stack веб-приложение для анализа попадания точки в заданную область на координатной плоскости.

## Обзор системы
Приложение предоставляет интерактивный интерфейс для работы с графиком, систему регистрации/авторизации и ведения истории проверок. Система построена на базе модульной архитектуры с использованием контейнеризации для обеспечения воспроизводимости среды.

## Технологический стек
*   **Backend:** Java 17, Spring Boot 3.4, Spring Security + JWT, Hibernate (JPA).
*   **Frontend:** React, Redux, React Toolbox.
*   **Database:** PostgreSQL.
*   **Инфраструктура:** Docker, Docker Compose, Gradle (Groovy DSL).
*   **Тестирование:** JUnit 5 (Unit-тесты), Playwright (E2E/Functional тесты).

## Основные возможности
*   **Безопасность:** Аутентификация через JWT-токены с использованием BCrypt для хеширования паролей.
*   **Локализация:** Поддержка i18n с автоматической конвертацией ресурсов через таску `native2ascii`.
*   **Автоматизация:** Полный цикл сборки: от версионирования манифеста до автоматизированного Git-коммита (таска `diff`).
*   **Тестирование:** Покрытие критических узлов модульными тестами и автоматизированный запуск 15 функциональных сценариев E2E.

## Контейнеризация и Docker
Приложение полностью контейнеризировано:
*   **Сборка:** Используется *Multi-stage Build* в Dockerfile, что позволяет собирать проект внутри контейнера и получать минималистичный финальный образ на базе `eclipse-temurin:17-jre-alpine`.
*   **Запуск:** Вся экосистема (PostgreSQL, Backend, Frontend) поднимается одной командой:
    ```bash
    docker-compose up --build
    ```

## Тестирование
Проект включает многоуровневую систему тестирования:
1.  **Модульные тесты (Unit):** Проверяют бизнес-логику расчетов попадания (математическая модель) и работу контроллеров с использованием Mockito.
    *   *Запуск:* `./gradlew myTest`
2.  **Функциональные тесты (E2E):** 15 сценариев на базе Playwright, проверяющих поведение пользователя в браузере (регистрация, вход, валидация полей, проверка точности графика).
    *   *Запуск:* `./gradlew functionalTest`

## Инструкция по сборке (Локально)
1.  **Подготовка:** Убедитесь, что установлены JDK 17, Node.js и PostgreSQL.
2.  **Конфигурация:** Укажите параметры подключения к БД в `backend/src/main/resources/application.properties`.
3.  **Сборка:**
    ```bash
    cd backend
    ./gradlew myBuild
    ```
4.  **Запуск:**
    *   Бэкенд: `java -jar build/libs/lab4-backend.jar`
    *   Фронтенд: `cd frontend && npm install && npm start`
